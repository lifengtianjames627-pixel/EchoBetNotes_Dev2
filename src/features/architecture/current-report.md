## 3. 前端架构

当前仍是 React + Vite 单页应用，不是 Next.js。

- **入口与横切层**：认证上下文、六语言上下文、React Query、React Router 和提示组件；共享 Layout 提供顶部导航、移动导航、通知、未读数、身份入口、内容订阅与页脚。
- **路由层**：首页/发现/乐评/播客/曲风/专辑/介绍/隐私/条款可浏览；个人、资料、私信、招募需登录；审核/统计/成员管理需管理员。前端门禁只改善体验，真正权限仍需服务端和数据规则执行。
- **页面层**：负责参数、状态及界面组合。Discover 本轮缩为组合页面，表单独立；既有 Profile、DirectChat、GenreSpace 等仍较复杂，尚未完成全部拆分。
- **领域层**：当前明确目录包括 reviews、location、soulmate、albums。reviews 已有读取/写入入口、纯规则、查询键和缓存刷新；location 已分离偏好、临时位置、定位采样、目录查询及界面；soulmate 有招募查询、私有海报和审核组件；albums 本轮增加发现查询/保存、添加窗口和六语言文案，尚非完整专辑域重构。
- **共享层**：通用 UI、身份安全显示、评论缓存兼容入口、站内私信入口和语言上下文。专辑写入通过共享缓存入口刷新，不新增跨域内部缓存算法。

逻辑流：页面/领域组件 → 查询或写操作 → 自托管 API 与 PostgreSQL → 经过权限与校验的持久结果 → 缓存失效/轮询更新 → 列表及详情重渲染。

静态计数：22个页面源文件（包含归档/未挂载页面），35个前端文件直接引用实体操作，100个 JSX 文件仍含行内样式。计数不等于缺陷数量；它表明领域边界和设计变量收敛仍是渐进任务，而不是已经全站完成。

## 4. 关键业务逻辑

### 音乐发现
读取最新100条，不冒充全量集合；搜索和曲风筛选作用于已加载集合。新增专辑校验标题/音乐人，空曲风不提交非法枚举，年份转为数字，初始评分与评论数为0。保存后刷新音乐及专辑缓存，关闭窗口；加载、空、处理中和失败状态可见。游客添加使用现有登录流程，游客身份下该跳转尚未自动验证。

### 招募发布与审核
服务端绑定登录作者，校验草稿、联系方式及安全声明；文字按招募专用规则分类，不复用专辑评论广告语境。正常内容可通过，不确定或审核服务异常转人工；图片始终待审。普通作者不能自行更新审核状态。年龄字段不再参与创建、读取、筛选或缓存。

### 私有海报
上传仍要求登录、合法图片类型/签名及5 MB限制，资产归属由服务端指定。帖子只保存资产ID，存储URI留在受限资产中。取图必须重新检查帖子访问、审核/活跃状态和作者归属，签发60秒临时链接。作者/管理员可看待审图片，其他登录成员仅可看允许公开的帖子；关闭年龄分组没有把海报变成永久公开文件。

临时链接在有效期内可被持有人使用，已下载副本不能追回；删除帖子使后续取图拒绝，不承诺已经签发的链接立即全部失效。

### 成员联系
昵称搜索要求至少2字，拒绝邮箱查询，每批读取100位用户、最多返回10个ID和昵称；使用User兼容的偏移分页，而不是它不支持的实体游标端点。资料查询要求登录，只返回公开资料所需字段及当前兼容用邮箱，不返回完整User记录。既有好友与非好友消息数量规则保留，本轮只移除年龄限制。

**完整去邮箱化尚未完成**：旧私信、好友和内容仍以邮箱关联；部分已授权响应及旧私信地址仍含邮箱。ID资料链接和昵称搜索不等于全站响应已经没有邮箱。

### 位置
保留独立网络发现同意、访问内存位置与长期位置的分离、撤回路径和近似坐标规则。无年龄门槛不意味着默认开启位置；本轮未重测真实设备授权/拒绝与多人位置可见性。

## 5. 权限与安全边界

- 招募公开分支：已登录普通用户可读活跃且通过审核的帖子；作者/管理员保留待审内容读取；创建须本人身份及待审；审核更新仅管理员；删除仅作者/管理员。
- 私有资产原有归属和管理员权限保留；匿名不能调用上传/取图/公开成员资料入口。
- 服务端昵称及资料的年龄拒绝已删除，账户认证没有删除。
- 展开看板安全提示现在显示完整免责声明，不再因compact模式略去末尾声明；发布前必须同意声明，联系方式过滤及举报机制保留。
- 不能把“管理员预览通过”写成“普通用户和游客隔离已通过”。普通身份、匿名拒绝、私信参与者隔离还需独立真实身份测试。

静态检查发现11个实体文件没有显式RLS，其中User由平台内置权限处理；其余10个包括公开目录及好友、置顶、投票、订阅、勋章和历史乐队关系等。公开目录与个人关系不能套同一种规则，应分别审查读取/创建/更新/删除。此项尚未整改完，不宣称全站安全完成，也未伪造跨账号通过结果。

## 6. 视觉与国际化

暖纸背景、暖黑文字、赭石强调和顶部导航保持。新发现界面使用已有语义色，缺失封面占位修复为暖纸色及可读文字。颜色主要由全局CSS及Tailwind映射管理，但历史组件仍有硬编码颜色和行内样式，不能称全站设计变量收敛完成。

新发现界面和更新后的参与规则有en/zh/ja/ko/fr/ru文案；用户专辑、评测和招募内容保持原文。已有内容翻译不因界面语言自动覆盖原文。未执行六种语言所有页面、弹窗和屏宽的全量回归；法律页及若干旧界面仍有固定语言文案。
